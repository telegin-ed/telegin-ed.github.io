## Why

В проекте отсутствует краткая справочная информация по Tilt — инструменту для разработки микросервисных приложений на Kubernetes и Docker Compose. Разработчикам приходится каждый раз обращаться к документации за базовыми командами и API. Cheatsheet ускорит вхождение в проект и стандартизирует подход к локальной разработке.

## What Changes

- Добавление файла `tilt/tilt.md` со справочной информацией по Tilt
- Разделы: что такое Tilt, установка (только Linux), базовый сценарий, Tiltfile API, CLI-команды, Live Update, CI, практические советы
- Каждый раздел содержит ссылку на источник (docs.tilt.dev)
- Целевой техстек для примеров: .NET Core, TypeScript
- Оформление аналогично `openspec-cheatsheet/openspec-cheatsheet.md`
