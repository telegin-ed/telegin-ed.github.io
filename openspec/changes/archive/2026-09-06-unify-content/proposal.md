## Why

Статьи на сайте написаны в разном стиле: одни содержат ручное оглавление в теле, другие нет; одни используют `<a id>`-якоря для навигации, другие полагаются на авто-генерацию; в двух статьях активно используются эмодзи, в остальных их нет. Это создаёт визуальный разнобой. Сайдбар уже умеет строить TOC из заголовков — ручные оглавления в теле статей дублируют его функционал и больше не нужны.

## What Changes

- Удалить ручные Table of Contents из всех статей (сайдбарное TOC работает через `assets/js/toc.js`)
- Удалить `<a id="...">`-якоря, которые использовались только для навигации из ручного TOC
- Конвертировать заголовки, обёрнутые в `<a id="...">`-теги, в чистые markdown-заголовки
- Удалить все эмодзи-символы из статей `linux-administration.md`, `linux-iptables.md` и `qwen-code-cli.md`
- Удалить горизонтальные разделители `---` из всех статей
- Блокцитаты и структура заголовков остаются без изменений
