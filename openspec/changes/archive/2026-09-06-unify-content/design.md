## Context

Сайт — Jekyll-сайт на GitHub Pages, тема `jekyll-theme-primer`. Семь статей в markdown с разным форматированием. Сайдбарное TOC уже работает через `assets/js/toc.js` — строит дерево из `h2, h3, h4` внутри `.markdown-body`. Ссылки в proposal.md.

## Goals / Non-Goals

**Goals:**
- Единообразный стиль оформления статей: без ручных TOC, без `<a id>`-якорей для навигации, без эмодзи
- Все заголовки — чистый markdown (без HTML-обёрток)
- Работающий сайдбарный TOC как единственный источник навигации

**Non-Goals:**
- Изменение структуры заголовков (h2/h3/h4 остаются как есть)
- Изменение блокцитат и контента
- Изменение index.md, layout-файлов, CSS, JS

## Decisions

| Decision | Rationale | Alternatives |
|----------|-----------|--------------|
| Удалять standalone `<a id>` целиком (c-sharp-concurrency pattern) | Якорь не нужен — заголовок ниже получит ID от `toc.js` | Оставить — не нужно, только мусор |
| Конвертировать `## <a id="x">Text</a>` → `## Text` | Чистый markdown, `toc.js` сам сгенерирует ID | Оставить обёртку — избыточно, мешает читаемости |
| Удалять эмодзи из текста, заголовков, таблиц, блокцитат | Решение в explore mode | Оставить — разнобой сохранится |
| Не трогать `<a id>` в `<!-- more -->`-подобных конструкциях, если такие есть | Они не для TOC | — |
| Удалять горизонтальные разделители `---` между секциями | Они не несут смысловой нагрузки, только визуальный шум | Оставить — допустимо, но нарушает единообразие |

## Risks / Trade-offs

| Risk | Mitigation |
|------|------------|
| Старые внешние ссылки вида `#ch1-1` перестанут работать | После изменений заголовки получат новые ID от slugify в `toc.js` (например, `типы-поддоменов` вместо `ch1-1`). Это ожидаемо — старые ссылки уже не поддерживаются, ручной TOC удаляется |
| Случайное удаление не-эмодзи символов при чистке | Каждый emoji проверять по Unicode-диапазону, не полагаться на визуальное сходство |
